# Verigate Authority

## Let AI prepare payments. Don't give it free control of your money.

AI agents can misunderstand a request, be manipulated or send funds to the wrong address. When an agent can pay, one mistake can become a real loss.

Verigate checks each payment against spending rules set by the user. It allows payments within those limits, asks for review when needed and blocks payments that break the rules. Every approval is tied to one exact transaction and cannot be changed or reused.

For teams building AI payment products, Verigate adds a control the system can enforce — not another instruction asking the AI to behave.

**The AI prepares. Verigate enforces the rules. The user keeps the keys and signs.**

The first integration is Anna, with a USDC wallet hand-off path for Base and Ethereum. The automated test suite reports **626 Python tests passed (4 skipped)** and **61 Anna UI end-to-end tests passed**.

**Current status:** Anna App 0.1.28 is still in Draft. A runtime test on an earlier version reached the MetaMask confirmation screen, but was cancelled before signing. No on-chain payment has been completed.
