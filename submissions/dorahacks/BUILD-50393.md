# Verigate Authority

## AI can prepare a payment. It should never control your money.

An AI agent can misunderstand instructions, be tricked or choose the wrong recipient. Verigate checks each payment against rules set by the user before it reaches the wallet.

Payments within the limits can proceed. Unusual payments go to the user for review. Payments that break the rules are blocked. Each approval is tied to one exact transaction and cannot be changed or reused.

**The AI prepares the payment. Verigate enforces the rules. The user keeps the keys and signs.**

The first integration is Anna, with a USDC payment path for Base and Ethereum. **626 automated tests passed (4 skipped); 61 Anna end-to-end tests passed.**

**Current status:** Anna App 0.1.28 is still Draft. Runtime testing reached MetaMask confirmation, but was cancelled before signing. No on-chain payment has been completed.
