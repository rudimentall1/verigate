# Verigate

## Give AI agents a job — not unlimited access.

Think of an AI agent as a new employee. You would not give it the keys to the whole company and hope it makes the right decisions. You would decide what it can access, what it can spend and which actions need approval.

AI agents need the same kind of control.

**Verigate is a permission system for AI agents.** It checks each proposed action against rules set by the owner before execution. Allowed actions receive a one-time, signed permission tied to the exact request. Change the request, exceed a limit or reuse the permission, and execution is rejected. The AI can request an action, but it cannot approve itself.

Verigate can also produce proof that others can verify independently. A team does not have to rely on the AI's word — or trust the system that ran it.

**Why it matters:** businesses can automate payments and other work without giving an AI unrestricted access to money or systems.

**Built:** an open-source protocol, working execution controls, ready-to-run demos and a proof checker that works offline. Anna is the first payment integration, with a USDC wallet path for Base and Ethereum.

**Status:** Anna App 0.1.28 is Draft. Runtime testing reached MetaMask, but no transaction was signed or broadcast. The project has 626 passing Python tests (4 skipped) and 61 passing Anna UI end-to-end tests.
